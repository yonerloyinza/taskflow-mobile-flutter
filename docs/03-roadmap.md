# Roadmap — taskflow-mobile-flutter

- [x] **Paso 0 — Aclaración de contexto:** Verificar `API_BASE_URL` (`--dart-define`), targets habilitados, Flutter 3.24+, Dart 3.5+, Xcode 15+, Android SDK, `build_runner` watch. **Nota: Android/iOS/Desktop requieren build local o CI con macOS runners; solo Web (WASM) build en VPS.**
- [x] **Paso 1 — Estructura Base e Infraestructura:** Scaffolding Flutter (`flutter create --org com.taskflow --platforms=android,ios,web,windows,macos,linux`), Feature-First structure, `core` + `features/tasks` + `app`, Riverpod Generator, Drift, Dio/Retrofit, GoRouter, Freezed, Material 3 + FlexColorScheme, `analysis_options.yaml` strict, `melos` (opcional).
- [x] **Paso 2 — Generación de Tipos y API Client:** `openapi-generator` (Dart/Dio) o manual → `freezed` DTOs + `json_serializable` + `retrofit` client desde `docs/openapi.yaml`, enums/status/priority sincronizados, `DioClient` con interceptors (Auth, Logging, Retry, Error mapping).
- [x] **Paso 3 — Persistencia Offline (Drift):** Esquema Drift (`@Table` Task), `Database` + `MigrationStrategy`, `TaskDao` (CRUD + `watch`), `LocalDataSource` + `RemoteDataSource` + `SyncRepository` (background sync, conflict resolution).
- [x] **Paso 4 — Domain & Data Layer:** Entities (`Task`, `TaskStatus`, `TaskPriority`), Repository interface, UseCases (`GetTasksUseCase`, `CreateTaskUseCase`, `UpdateTaskUseCase`, `DeleteTaskUseCase`), RepositoryImpl con `AsyncValue` + optimistic updates.
- [x] **Paso 5 — Presentation Layer (Riverpod + GoRouter):** Providers (UseCases, Repository, ViewModels), `AsyncValue` UI State, `StateNotifier` para mutaciones, GoRouter routes tipadas (`/tasks`, `/tasks/:id`), Deep linking.
- [x] **Paso 6 — UI Core & Theming:** Design System (Button, Input, Select, Chip, Card, Modal, List, Pagination, SnackBar, Loading, Empty), `ThemeData` light/dark + dynamic color, Responsive (Breakpoints), Accessibility (Semantics, Focus).
- [x] **Paso 7 — Feature: Tasks CRUD:** Lista paginada con filtros (status, priority, assignee) + `AsyncValue` + Pull-to-refresh + Infinite scroll, Crear/Editar (Modal/Page + `Formz` validation + `reactive_forms`), Eliminar (SwipeAction + Confirmation), Offline-first (local write → background sync).
- [ ] **Paso 8 — Platform Specifics:** Android (Notifications, Permissions, Shortcuts, Play Integrity), iOS (Capabilities, Universal Links, App Clips), Web (PWA Manifest, Service Worker, WASM), Desktop (MenuBar, Tray, Window Controls).
- [ ] **Paso 9a — Documentación y Build Local:** AGENTS.md actualizado, docs/01-architecture.md, `flutter analyze`, `flutter test`, `flutter build apk/aab/ipa/web/windows/macos/linux` all flavors (local).
- [ ] **Paso 9b — CI/CD Multi-target:** GitHub Actions / Codemagic matrix → Android (AAB), iOS (IPA via Xcode Cloud), Web (WASM → VPS Docker), Desktop (installers). Signing automatizado. Deploy: Play Console, TestFlight, GitHub Releases, VPS (Web + nginx + Traefik).
